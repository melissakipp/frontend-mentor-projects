# Project Documentation

Welcome to the **GitHub User Search** project documentation.

<br />

## Local Development

<br />

Run: `bash npm install npm run dev `

<br />

## Docker Development

Build the image:

```bash
docker build -t github-user-search .
```

Run the container:

```bash
docker run -p 3000:3000 github-user-search

```

Navigate to [http://localhost:3000](http://localhost:3000).

<br />

✅ View user profiles
